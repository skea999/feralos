# Performance Checklist

- [ ] Bundle: tree-shake, code-split, lazy-load
- [ ] Assets: compress images, use WebP, lazy loading
- [ ] Cache: CDN, HTTP cache headers, SW
- [ ] DB: index queries, avoid N+1, connection pool
- [ ] Rendering: memoize, virtualize lists, avoid re-renders
- [ ] Network: batch requests, debounce, prefetch critical
- [ ] Monitoring: LCP, FID, CLS budgets
- [ ] Cost: optimize cold starts, reduce lambda duration
