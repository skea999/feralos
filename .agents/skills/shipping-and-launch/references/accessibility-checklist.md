# Accessibility Checklist

- [ ] Keyboard: all interactive elements reachable via Tab
- [ ] ARIA: roles, labels, states where HTML semantics insufficient
- [ ] Contrast: WCAG AA (4.5:1 text, 3:1 large text)
- [ ] Screen readers: alt text, aria-live regions, focus management
- [ ] Forms: label→input association, error announcements
- [ ] Touch: minimum 44x44 tap targets
- [ ] Motion: respect prefers-reduced-motion
- [ ] Zoom: no horizontal scroll at 200%
- [ ] Color: never convey info by color alone
