# Webmin — Web Administration Panel

> Web-based system administration for FeralOS. Installed as a standalone binary after first boot.

---

## Overview

Webmin provides a web interface for managing:
- Firewall (FirewallD)
- Packages (apk)
- Disk/Filesystems (btrfs)
- SMART disk health
- Processes
- Cron jobs
- Logs
- Custom commands (btrbk, nix)

Webmin runs in a Podman container with minimal capabilities.

## Installation

Webmin is installed automatically when `enableWebmin: true` in `variables.yaml`.

### What happens during install

1. Installer compiles `/opt/feralos_webmin` binary
2. After first boot, run `/opt/feralos_webmin` to:
   - Configure Podman (storage driver btrfs, cgroups, subuid/subgid)
   - Create `/opt/webmin/` directory structure
   - Generate `docker-compose.yml`
   - Generate module configs
   - Start Webmin container via `podman compose up -d`
   - Create oneshot service (dual-init, PID1 via `cat /proc/1/comm`): dinit → `/etc/dinit.d/webmin-ensure` (scripted, `depends-on = local.target`) + `/usr/libexec/dinit-webmin-ensure` script + boot.d link; OpenRC → `/etc/init.d/webmin-ensure`
   - Create `.desktop` file for Firefox PWA

### Manual Installation

```bash
# Run the installer binary (standalone, like feralos_secureboot/tpm)
# Podman is already configured in chrootPhase (btrfs driver, cgroups, subuid/subgid)
# Binary only verifies podman --version, seeds config, starts container
/opt/feralos_webmin

# Or configure manually
mkdir -p /opt/webmin/{config,commands}

# Start with podman compose
cd /opt/webmin && podman compose up -d
```

## Quick Start

`/opt/webmin/docker-compose.yml` generated by the installer:

```yaml
services:
  webmin:
    image: docker.io/demosthenesk/webmin:noble
    container_name: webmin
    hostname: feralos-webmin
    restart: unless-stopped
    read_only: true
    cap_drop:
      - ALL
    cap_add:
      - SYS_CHROOT
      - NET_BIND_SERVICE
      - AUDIT_WRITE
      - SETUID
      - SETGID
      - FOWNER
      - DAC_OVERRIDE
      - SYS_ADMIN
    ports:
      - "127.0.0.1:10000:10000"
    volumes:
      - /opt/webmin/config:/etc/webmin
      - /opt/webmin/commands:/etc/webmin/custom/commands
      - /etc:/host/etc:ro
      - /var:/host/var:ro
      - /proc:/host/proc:ro
      - /sys:/host/sys:ro
      - /run:/host/run:ro
      - /boot:/host/boot:ro
      - /home:/host/home:rw
      - /root:/host/root:rw
    tmpfs:
      - /tmp
      - /run
      - /var/log
      - /var/webmin
```

> **Note:** First run seeds `/etc/webmin` from the image (`webmin-seed` container) — needed because the config bind mount shadows the bundled `miniserv.conf`.
>
> **Image:** `docker.io/demosthenesk/webmin:noble` (pschatzmann dead — webmin 1.820 2016). Verified 2026-09-02.

## Container Management

```bash
# Status
cd /opt/webmin && podman compose ps

# Logs
cd /opt/webmin && podman compose logs webmin

# Restart
cd /opt/webmin && podman compose restart

# Stop
cd /opt/webmin && podman compose stop

# Update
cd /opt/webmin && podman compose pull && podman compose up -d

# Full cleanup (keeps config)
cd /opt/webmin && podman compose down
```

## Security

- **Container isolation** — Podman, not host
- **Minimal capabilities** — Only necessary Linux capabilities
- **Read-only root** — Immutable container filesystem (`tmpfs: /tmp /run /var/log /var/webmin` writable)
- **Persistent config** — `/opt/webmin/config/` survives restarts
- **HTTPS only** — SSL by default
- **Storage driver** — btrfs (native, via `sed` on `/etc/containers/storage.conf`)
- **No global temp-dir leak** — nix uses the upstream default build dir (`/tmp`, mounted exec); the old daemon-scoped temp override that leaked into podman is gone

## Implementation Notes (recent fixes)

- **Locale:** `it` → `it_IT.UTF-8` expansion (same as shell reference; bare `it` crashes `conmon` `setlocale`)
- **Nix temp dir:** upstream default (`/tmp`, exec since round 48) — old scoped override leaked into podman caused `containers-storage` failure, hence removal
- **Heredocs:** quoted heredocs (`<< 'COMPOSE'`) — no escaping, prevents broken `webmin-ensure` script
- **Binary:** exits 1 on compose failure, verifies `podman ps` after start — harness reports honestly
- **Divider:** `---` horizontal rule separates Quick Start / Directory Structure / Implementation Notes for readability
