## Root

All harness outputs under repo-relative `tests/artifacts/harness/` (resolved via `detectRepoRoot` in `cmd/skea_harness/main.go`, `artifactsRoot = <repo>/tests/artifacts/harness`). Created on demand; structure preserved by `.gitkeep`.

```
tests/artifacts/harness/
├── cache/
│   ├── base-images/        # Debian genericcloud qcow2 (downloaded once)
│   ├── runner-images/      # skea-runner.qcow2 (overlay+resized 8G)
│   ├── keys/               # id_ed25519 / id_ed25519.pub (guest.EnsureKeyPair)
│   └── web/alpine/         # cache-first Alpine mirror (cache.HTTPMirrorServer)
├── prepare/<timestamp>/    # one per prepare-runner (keep last 1)
│   ├── serial.log, qemu.log
│   ├── seed.iso, user-data, meta-data
│   └── qmp.sock
├── runs/<timestamp>/       # one per run (keep last 2, cleanOldRuns)
│   ├── install-disk-1.qcow2 [, install-disk-2.qcow2]  # 16G default (qemu.CreateDisk)
│   ├── runner-serial.log, runner-qemu.log, runner-qmp.sock
│   ├── installer.log, post-install.log, harness.log (run summary at end), sbctl.log, tpm-post-install.log
│   ├── target-serial.log, target-qemu.log, target-firmware.log, tser.sock, target-qmp.sock
│   ├── verify.md (markdown summary table — converted from verify.log; SSH warnings stripped, detail truncated), OVMF_VARS.fd
│   ├── tpm.sock, tpm.sock.ctrl, tpm-state/, tpm.pid, tpm.log
│   ├── repo.tgz, variables.yaml, git/bash/fdisk shims
│   ├── target-serial-clevis-reboot.offset
│   └── tests/                        # verification results (per-run)
│       ├── summary.md                # markdown table: check | status | detail
│       └── <check_name>.txt          # individual check: PASS/FAIL + detail
└── state/active.json       # runstate.Store — ActiveRun{RunID, Mode, Phase, RunDir, QMP paths, serial logs, SSH ports}
```

## Retention

- `prepare/` keeps last **1**, `runs/` keeps last **2** (`service.cleanOldRuns`). Older dirs pruned at start of next `prepare-runner` / `run`.
- `cache/` never pruned automatically — delete manually to force re-download/rebuild.

## Inspecting logs

Per-run logs listed above; `service.Logs` tails them:

```bash
# via binary
go run ./cmd/skea_harness -- logs --log installer --run-dir tests/artifacts/harness/runs/2026-08-27T10-00-00Z --lines 200
# or compiled
./skea-harness logs --log installer
./skea-harness logs --log target-serial --lines 500
./skea-harness logs --log verify
```

Log names: `installer`, `post-install`, `runner-serial`, `runner-qemu`, `target-serial`, `target-qemu`, `verify`, `harness` (`parseLogsArgs` in `cmd/skea_harness/main.go`). Without `--run-dir`, resolves latest run via `runstate`.

Raw inspect: `cat tests/artifacts/harness/runs/<ts>/installer.log`, `tail -f target-serial.log`, `cat verify.md`.

## Config marker checks

Each run produces per-check result files under `tests/`. 4 marker checks verify installer wrote config files — grep each file for `# Generated by FeralOS Installer`, `grep -c` must be > 0:

- `cmdline_marker` — `/etc/kernel/cmdline`
- `booster_marker` — `/etc/booster.yaml`
- `fstab_marker` — `/etc/fstab`
- `network_marker` — `/etc/network/interfaces`

All 4 layouts PASS 35/35 with markers enabled. Markers appended at END of each config file (single-point verification). See `tests/harness/internal/checks/` for implementation.

## Additional harness checks (post-2026-09-02)

| Check | What it verifies | Pass condition |
|-------|------------------|----------------|
| `trusted_users_clean` | Nix `trusted-users` temp injection cleaned | `! grep -q "<user>" /etc/nix/nix.conf` (user added during chroot install, then cleaned via `sed -i 's/trusted-users = root .*/trusted-users = root/'`) |
| `nix_packages_missing` | Expected nix profile packages installed | `nix profile list` count >= expected (7 for niri: quickshell, dms-shell, rclone, rclone-ui, mission-center, nix-software-center, cups-browsed; 1 otherwise) |
| `nix_build_tmp_perms` | Nix build tmp world-writable | `stat -c %a /nix/var/nix/build/tmp` contains `777` (1777) |
| `chmod_77_check` | No insecure chmod in installer.log | Count `chmod 777`/`chmod 1777` excluding `/nix/var/nix/build/tmp` (which SHOULD be 1777) must be 0; previous check flagged `775` false positive |
| `works_in_real_life` | No ignored errors | `installer.log` must NOT contain `[WARNING] Non-interactive mode: ignoring error and continuing.` |
| `webmin_binary` | Webmin firstboot binary present | `test -x /opt/feralos_webmin` |
| `webmin_container` | Webmin container running | `podman ps --format '{{.Names}}' \| grep -q '^webmin$'` (no `|| echo` fallback — must FAIL when not running) |
| `webmin_port` | Webmin port mapped | `podman port webmin 10000 \| grep -q 10000` |
| `webmin_http` | Webmin HTTP answering | `wget -q -T 5 --no-check-certificate https://localhost:10000/` retry 8×5s |
| `podman_*` | Podman functional | `podman info`, `podman ps` etc. when `enablePodman=true` |

**Nix tmp permissions:** `/nix/var/nix/build` is `775` + `chown root:nixbld`; `/nix/var/nix/build/tmp` is `1777` + `chown root:nixbld` (world-writable sticky). Required because `/tmp` is `noexec` + `0755` for security, so nix temp must live on `@nix-var-nix-build` subvolume. `TMPDIR` scoped to daemon only via `/etc/conf.d/nix-daemon` (not global export — leaked into podman and broke `containers-storage`).

**Podman storage driver:** `btrfs` via `sed` on `/etc/containers/storage.conf` (keep Alpine's full config, override only `driver` line). `cgroups` service enabled alongside `podman`. `fuse-overlayfs` kept as fallback for rootless overlay. `iptables` added to package set.

**Webmin:** `demosthenesk/webmin:noble` image (pschatzmann dead), config seeded via `webmin-seed` container before first start, `tmpfs` for `/tmp /run /var/log /var/webmin` with `read_only: true`, quoted heredocs, binary exits 1 on compose failure.

**Harness result:** 45/45 PASS including `webmin_http` functional check with `demosthenesk` image.

## Cache reuse

- `cache/base-images/<file>` keyed by URL basename; `cache.EnsureDownloaded` skips if present.
- `cache/runner-images/skea-runner.qcow2` reused unless `--force`.
- `cache/keys/id_ed25519` generated once, reused for runner+target SSH.
- `cache/web/alpine/` persists upstream Alpine APKs; `StartHTTPMirrorServer` serves it guest-side to avoid re-downloading.
